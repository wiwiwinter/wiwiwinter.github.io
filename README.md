# Edgar, Jr. B. Villas · Portfolio

Personal engineering and design portfolio of **Edgar, Jr. B. Villas** (`@wiwiwinter` / `@ejejejvillas`), Computer Engineer (Cum Laude, MSU-IIT) and multidisciplinary designer based in Koronadal City, Philippines.

## Overview

A static, zero-dependency portfolio showcasing embedded firmware, edge AI computer vision, bare-metal robotics, and UI/UX and hardware enclosure design. Includes a playable browser port of **Tower of Power**, an 8051 Assembly game originally built for the AT89C52 microcontroller and dual 8x8 LED matrices.

## Structure

```text
.
├── index.html      # Main portfolio markup (flagship builds, archive, experience)
├── css/
│   └── style.css   # Paper-datasheet light theme, responsive layout, and interactions
├── js/
│   └── main.js     # 8x8 LED matrix game, project archive filter/search, and chip navigation
└── README.md       # Project documentation
```

## Running Locally

Open `index.html` directly in any browser, or serve the folder locally:

```powershell
npx serve .
```
