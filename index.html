01Edge AI · Analog Devices MAX78000

MAX78000 Edge AI Visual Classifier

Deployed a 7-layer convolutional neural network on the MAX78000 Feather board's hardware CNN accelerator with live camera capture. A DMA stream feeds 128x128 RGB888 frames into the CNN FIFO, normalizes pixel ranges to [-128, 127], and runs real-time softmax classification with on-board LED and 115200-baud serial feedback.

  • C
  • MAX78000 FTHR
  • 7-layer CNN
  • DMA Camera Stream
  • MaximSDK
View source on GitHub

02Embedded Instrument · ESP32 + 3D Enclosure

Handheld ESP32 Lux Meter & Telemetry Logger

Digital light meter combining an ESP32, a TSL2591 sensor with automatic gain stepping (1x, 25x, 428x, 9876x), and an SSD1306 I2C OLED inside a custom 3D-printed enclosure (STL and 3MF files included). Streams 500 ms CSV telemetry over Bluetooth to a companion browser dashboard that plots live lux curves and exports logs.

  • C++ / ESP32
  • TSL2591 I2C
  • SSD1306 OLED
  • Bluetooth Telemetry
  • 3D CAD (STL / 3MF)

03Bare-Metal Robotics · AVR C

Autonomous Wall-Following Robot Firmware

AVR C firmware for an autonomous mobile robot that tracks walls using an ultrasonic distance sensor mounted on a scanning servo. Built without heavy frameworks using hardware timer timekeeping, PWM motor and servo control, interrupt-driven ultrasonic echo capture, and a compact navigation state machine.

  • Embedded C
  • AVR Microcontroller
  • Hardware PWM & Timers
  • Interrupts
  • State Machine
